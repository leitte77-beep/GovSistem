# Manual do Usuário (Servidor Municipal)

## Criar matéria
1. Painel → **Matérias → Nova**.
2. Etapa 1 **Informações**: tipo de ato, número/ano/data, secretaria, responsável.
3. Etapa 2 **Conteúdo**: digite (editor TipTap) ou importe um PDF/DOC. O conteúdo é salvo no servidor
   (autosave) e versionado.
4. Etapa 3 **Conferência**: confira o texto antes de enviar.

## Enviar para revisão
- Clique **Enviar para revisão**. A matéria vai para o fluxo editorial (não é publicada).

## Revisar / aprovar
- **Revisor**: abre a matéria em `REVIEW`, confere e **Aprova** ou **Devolve** (com motivo).
- Separação de funções: quem criou a matéria normalmente não a aprova (política four-eyes).

## Criar edição
- Painel → **Edições → Nova**. A numeração é automática (e protegida contra duplicação).

## Montar edição
- Adicione matérias **aprovadas**, ordene (arrastar), defina seções. Gere sumário automaticamente.

## Conferir edição
- Visualize a edição como ficará (preview real = mesmo motor do PDF final).

## Assinar
- Com o certificado ICP‑Brasil (A1) ativo, assine a edição. O signer valida a assinatura.

## Carimbar / validar
- Quando houver TSA/ACT configurada, aplica-se o carimbo do tempo. A assinatura é validada.

## Publicar
- A ação é confirmada; **após publicar, a edição é imutável**. Erros levam a **errata**/
  **retificação** (novo ato ligado ao original), nunca a reescrever o publicado.

## Consultar histórico
- **Auditoria** mostra todas as ações; **Relações** vincula retificações/revogações.

## Retificar
- Crie a matéria com `publication_type=rectification`, referenciando a original, e relacione.

## Verificação pública
- O cidadão usa o código verificador (formato `XXXX-XXXX-XXXX-XXXX`) ou o QR Code.
